# SEO Growth Loop

## Positioning

Audio Software Hub is a utility-first music production software directory. Content should help producers discover, filter, compare, and verify tools quickly.

## Weekly Loop

1. **Monday: Demand scan**
   - Pick one category cluster and one use-case cluster.
   - Add target pages with primary keyword, search intent, and source notes.
2. **Tuesday: Production**
   - Prioritize category hubs, use-case pages, platform/format pages, comparisons, tool details, and freshness pages.
3. **Wednesday: Freshness**
   - Check version, pricing, OS, plugin formats, trial/free status, official URL, and `lastChecked`.
4. **Thursday: Internal linking**
   - Link pages to useful adjacent categories, use cases, and related tools.
5. **Friday: Quality and indexing**
   - Verify metadata, canonical slugs, sitemap coverage, and Search Console opportunities.

## Priority Page Types

- Category hubs: broad discovery and crawl structure.
- Use-case pages: workflow-specific intent, such as free wavetable synths or LUFS meters.
- Platform/format pages: VST3, AU, CLAP, Windows, macOS, Linux, standalone.
- Comparison pages: alternatives and decision-stage queries.
- Tool detail pages: one canonical page per product.
- Freshness pages: new plugins this month, recently updated tools, free releases.

## Required Fields

- Primary keyword
- Search intent
- Title tag
- Meta description
- Canonical slug
- Category
- Software names
- Developer
- Official URL
- Pricing model
- Platforms
- Plugin formats
- Last checked date
- Internal links

## Quality Gates

- No generic hype language.
- No thin pages with generic descriptions.
- Verify official links instead of pointing at download mirrors.
- Include freshness dates for tool and comparison pages.
- Add useful internal links based on real workflow adjacency.
- Keep one canonical URL per tool, category, and comparison.
